# 安全 SECURITY

## 监听面

- 控制台 `wang_service.py` 默认 `WANG_BIND=127.0.0.1`（仅回环）。它只应被本机的
  relay 访问；不要把它直接暴露到 LAN。
- 中继 `relay.js` 需要被 WSL/容器访问，因此默认监听 `0.0.0.0`。**这会把你回环上的
  网关/代理重新暴露到局域网**。生产或个人敏感环境请：
  - 设置 `WANG_RELAY_BIND` 为 WSL 虚拟网卡地址，或
  - 用 Windows 防火墙把 13425/17897/18790 限定为仅本地子网，或
  - 不需要时不要启动对应中继（编辑 `WANG_RELAYS`）。
- 平台前端/REST 通过容器映射到 `127.0.0.1:3000`，默认不外暴露。

## 凭据

- 仓库**不含任何凭据**。网关 API Key 通过环境变量 `MAGPIE_API_KEY` 传入，留空表示
  网关免密钥。
- 平台账号/Key 由首次启动生成，存于容器卷与本机文件，均被 `.gitignore` 排除。
- 不要把 `*.env`、`platform-info.txt`、`ai-order.json` 提交进仓库。

## 输入处理

- 控制台对所有来自网关/状态文件的字符串做 HTML 转义后再渲染；模型 ID 走
  `data-*` + 事件监听，不拼进 `onclick`；探活结果用 `textContent` 渲染。
- 控制台对上游做主机白名单 + 私网/回环校验（SSRF 防护），不接受任意 URL。
- 状态文件写入使用临时文件 + 原子替换。

## 桌面端

- 服务启动通过固定路径脚本 + `ShellExecute`（无参数、无 shell 拼接）。
- WebView2 禁用 DevTools 与宿主对象；新窗口一律在当前窗口内导航。

## 报告漏洞

请通过仓库 Issues 或私密渠道联系维护者，勿在公开渠道贴利用细节。
