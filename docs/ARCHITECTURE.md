# 架构 ARCHITECTURE

```
┌─────────────────────────────── Windows 主机 ───────────────────────────────┐
│                                                                            │
│  王将军AI工作台.exe (WPF + WebView2)                                        │
│     │  加载 http://localhost:3000（平台前端）                                │
│     │  注入品牌脚本；托盘常驻；返回/前进/刷新                                  │
│     └─ 服务自检失败时调用 wang-service-start.bat                             │
│                                                                            │
│  relay.js (node)                                                           │
│     13425 → 127.0.0.1:3425   LLM 网关（Magpie 等，仅监听回环）               │
│     17897 → 127.0.0.1:7897   HTTP 代理（可选）                               │
│     18790 → 127.0.0.1:8790   自有控制台                                      │
│                                                                            │
│  wang_service.py (python, 8790, 仅 127.0.0.1)                               │
│     /wang/ai-order   模型优先级 + 角色指派                                    │
│     /wang/magpie     网关状态 + 逐模型探活                                    │
│                                                                            │
└───────────────────────────────┬────────────────────────────────────────────┘
                                │ WSL2 (NAT)
┌───────────────────────────────▼────────────────────────────────────────────┐
│  WSL 发行版（默认 wang-workbench）                                            │
│     socat 中继: 13425/17897/18790 → Windows 网关 IP（容器可达）               │
│     Docker 容器（默认 wang-workbench）= AutoGPT 官方单容器镜像                 │
│        nginx :3000 → 前端/REST/WebSocket                                     │
│        /wang/  → 反代到 172.17.0.1:18790 → relay → 控制台                     │
│        后端 magpie 供应商 → MAGPIE_BASE_URL（经中继到主机网关）                 │
└────────────────────────────────────────────────────────────────────────────┘
```

## 关键设计

- **不 fork AutoGPT**：官方镜像原样运行；LLM 供应商与前端定制都以「挂载补丁文件 /
  构建产物改写」叠加，升级镜像后重跑补丁即可。
- **回环优先**：网关与控制台默认只监听 127.0.0.1；跨 WSL/容器访问统一走显式中继，
  中继地址与端口全部可配。
- **桌面壳只做三件事**：承载网页、管理窗口/托盘、保证本机服务在跑。业务逻辑都在
  平台与控制台里。
